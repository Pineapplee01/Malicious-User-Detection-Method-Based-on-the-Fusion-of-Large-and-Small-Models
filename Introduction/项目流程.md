
## 一、 整体流程

### 1. 数据准备
- `preprocess_llm.py`：把原始数据清洗/规整为 processed_data 目录下的张量与索引。
- `prepare_llm_features.py`：调用 llm_feature_extractor.py 批量生成/缓存用户 LLM 增强特征文件（.pt）。
训练与验证
- `data_loader_llm.py`：读取 processed_data 与（可选）LLM 特征，拼接成节点特征矩阵 x，构建 PyG Data/NeighborLoader 所需字段，返回 pretrain_data 与 finetune_data。
- `SeGA_LLM.py`：模型主体（PyTorch Lightning）。完成多通道特征编码、GNN 信息传播、分类头、训练/验证/测试 step。
- `main_llm.py`：训练入口（Lightning 训练器）。解析参数、调用 load_data_llm、创建 SeGA_LLM、设置回调与 Trainer 并启动预训练/微调。
- `simple_gnn.py`、`simple_run.py`、`main_s.py`：轻量版训练/实验路径。simple_gnn 提供简化的 GNN 层；simple_run.py 给出最小训练脚本；main_s.py 含 MetricsTracker（记录与持久化每个 epoch 的 train/val 指标、预测与测试结果）。

### 2. 评估与可视化
- `evaluate.py`、`model_test.py`、`model_test_curves.py`：离线评估、绘制 ROC/PR/学习曲线等。
- `generate_plots.py`、`model_analysis.py`：训练结果与嵌入分析可视化。
- `visualize_processed_data.py`、`test_processed_data.py`：对 processed_data 的特征分布、边分布、标签分布进行检查与单测。
- `direct_test.py`、`minimal_test.py`：加载 checkpoint 做快速推理/最小验证。
运行脚本与配置
- `run_model.bat`、`run_model_simple.bat`、`run_simple.bat`、`run_direct_test.bat`：Windows 一键运行入口。
- `checkpoints/`、`output/`、`runs/`：模型权重、导出嵌入与 TensorBoard 事件文件。
- `globals.py`：训练过程的全局状态/日志收集（供 main_llm 使用）。
- `README.md`、项目说明.md、TEST_README.md：文档与说明。
- `requirements.txt`：依赖清单。

## 二、核心模块与相互依赖

### 1. LLM 特征链路
- `llm_feature_extractor.py`
`extract_llm_enhanced_features`：从用户描述/推文生成 base/LLM/tweet 三路特征并拼接为 `enhanced_features`（维度通常为 2304）。
`_generate_description_prompt`/`_generate_tweet_prompt`：构造对 LLM 的分析提示词。

- `prepare_llm_features.py`
批量遍历用户文本，调用 `LLMFeatureExtractor`，生成并保存 `user_llm_features.pt` 等缓存文件。

- `data_loader_llm.py`
`load_data_llm`：读取基础数值/分类/文本特征与可选的 LLM 增强特征；若缺失或通过 `ablate_llm` 关闭，则用全零填充。注意 ablate_llm 参数：getattr(args, "ablate_llm", True) 控制是否启用缓存的 LLM 特征。

### 2. 模型与图学习
- `SeGA_LLM.py（核心）`
特征切片：cat/numeric/tweet/description/llm 五路；五个线性层映射到统一 embed_dim，并经 ReLU+Dropout；hidden_layer 融合五路特征；
GNN：支持 DeepGCN（PyG 的 GENConv + DeepGCNLayer）或自定义 SimpleGCNLayer（来自 simple_gnn.py）多层堆叠，聚合邻居信息；
out_layer + classifier（3 类：bot/human/troll）；
training_step/validation_step/test_step：Lightning 风格训练流程，计算交叉熵与指标。

- `simple_gnn.py`
定义 SimpleGCNLayer 等简化图卷积层，作为 SeGA_LLM 的后备或 simple_run 的主力层。
训练入口与控制

- `main_llm.py`
parse_args：数据路径、设备、encoder、batch_size、pretrain/finetune 开关、epoch/finetune_epochs 等；
train：构建 NeighborLoader（预训练/微调索引）、实例化 SeGA_LLM、设置 ModelCheckpoint、pl.Trainer(max_epochs=...) 并执行训练；读写 checkpoints 与 output。
关键信号：max_epochs 由命令行参数控制；是否从预训练权重恢复、是否只微调等。

- `simple_run.py` / `main_s.py`
自定义循环版本：不依赖 Lightning 的 Trainer；main_s.py 的 MetricsTracker 负责记录每个 epoch 的 loss/acc/f1、测试结果与预测。

### 3. 数据与可视化
- `visualize_processed_data.py`
对 pretrain/finetune 的 x、edge_index、y 做直方图/计数图，支持标签映射与刻度控制。
evaluate.py、model_test*.py、generate_plots.py、model_analysis.py
统一评价与曲线绘制，分析 embeddings、混淆矩阵、学习曲线等。


## 三、典型调用链

### 1. 预处理阶段
运行 preprocess_llm.py 生成 processed_data。
运行 prepare_llm_features.py 生成 LLM 增强特征缓存（可选）。

### 2. 训练阶段
main_llm.py → parse_args → load_data_llm → 构建 SeGA_LLM → Trainer.fit
训练结束保存 best ckpt 到 checkpoints/output。

### 3. 评估与分析
evaluate.py / model_test.py 加载 ckpt 做离线评估；
generate_plots.py / visualize_processed_data.py 绘图检查数据与结果；
direct_test.py 快速推理。

## 四、关键参数与开关（跨文件）

- ablate_llm（data_loader_llm.py, main_llm.py）：是否启用 LLM 增强特征。
- encoder（main_llm.py → SeGA_LLM.py）：DeepGCN 或 SimpleGCN。
- list_cat_num/list_numeric_num/list_tweet_channel/list_des_channel/- llm_enhancement_channel（SeGA_LLM.py）：五路特征维度配置。
- pretrain vs finetune（main_llm.py, SeGA_LLM.py）：两阶段训练逻辑与数据索引。
- max_epochs/finetune_epochs、batch_size、devices（main_llm.py）：训练控制。

## 五、小结

项目以 SeGA_LLM.py 为核心模型，data_loader_llm.py 负责拼装五路特征，llm_feature_extractor.py/prepare_llm_features.py 生成 LLM 语义增强特征；main_llm.py 驱动两阶段训练；simple_* 与 main_s.py 提供简化实验路径；evaluate/visualize 系列用于评估与可视化。整体结构清晰，模块边界明确，便于替换特征通道或 GNN 编码器。
